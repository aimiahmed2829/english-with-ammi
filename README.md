# English With Ammi

A free, friendly, phone-first English speaking crash course for an adult Urdu-speaking beginner living in Canada.

**The actual website is the single file `index.html`.** No coding knowledge, apps, login, database, API key, or subscription is required.

## What is inside

- **21 lessons** divided into three easy weeks, with about **15 minutes of practice per day**.
- **105 everyday English sentences**, each with an **Urdu translation** and a **Listen** button.
- **105 vocabulary words**, 21 short dialogues, one little multiple-choice question per day, and one practical speaking mission per day.
- Familiar scenarios: introductions, shopping, checkout, directions, weather, appointments, pharmacy, phone calls, community classes, work, home repairs, and asking people to repeat themselves.
- A searchable **Phrasebook**, adjustable text size, slow speech option, and optional record-and-replay microphone practice.
- Local progress tracking: she can leave and return **on the same browser and device**.

## How she uses it

1. Open the website link on her phone.
2. Tap **My lesson** and begin at Day 1.
3. Tap **Listen** and **say each English sentence out loud** two or three times.
4. Hear the short conversation, then try saying both parts herself.
5. Choose the answer to the easy practice question.
6. Try the daily speaking mission and tick **I practised speaking aloud!**
7. Tap **Finish Day**. Come back tomorrow for the next lesson.

**Important:** No one needs to be perfect. Confidence builds through many short, relaxed speaking attempts.

## Publish for free with GitHub Pages

The website becomes a shareable web link after you publish it. It has **not** been published just by downloading these files.

1. While signed in to your GitHub account, open <https://github.com/new>.
2. Create a new repository named `english-with-ammi` and set its visibility to **Public**. Do not put the files in an unrelated project.
3. Open the new repository. Select **Add file → Upload files** (you may first need to complete its initial setup). Upload **`index.html`** from this package directly into the repository's **top level** (not inside a folder, and not as an unopened ZIP file). Optionally add this `README.md` too.
4. Commit the changes to the `main` branch.
5. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then **Save**.
6. Wait for Pages deployment, then use the **Visit site** link on the Pages settings screen. If you used the suggested name and owner, the address normally follows this pattern:

   `https://aimiahmed2829.github.io/english-with-ammi/`

   **This is the expected URL pattern, not a confirmation that the website is live.** Use the actual URL shown by GitHub Pages when deployment succeeds.
7. Send that link to Ammi in WhatsApp or another messaging app. She can bookmark it or add it to her iPhone Home Screen.

**Shortcut:** If you create the empty public GitHub repository and share its repository URL back in ChatGPT, the already-connected GitHub app can add the course file for you.

## Browser notes

- **Listen** uses the phone or computer's built-in English text-to-speech voices. Voice and pronunciation quality vary by device and browser; Safari on iPhone and Chrome on Android are good choices to try.
- Microphone recording is optional, requests permission, and is kept in browser memory only. It is not sent to a server and disappears on refresh or when leaving.
- The progress record is saved in local browser storage, **not to GitHub or an online account**. It will not automatically sync between phones and can be lost if she clears website data or uses private browsing.
- No internet connection to a third-party content service is used by the course; while the online site needs access to be opened, the content itself is self-contained.
- To update the course, replace `index.html` in the GitHub repository and wait for GitHub Pages to republish.

## Privacy

No advertisements, account registration, analytics, uploads, or external assets are built into this website. Microphone use is entirely optional.
